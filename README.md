# Hi, I'm Ryan

I ran a moving company for nine years. I started it with one truck and grew it to 25 people doing hundreds of moves a year around Portland, and I handled everything from dispatch and hiring to quotes and payroll.

Running it showed me where service businesses lose time and money, so now I build the automation that fixes that. I design the systems, write the specs and acceptance criteria, and direct AI coding agents to build them. Then I test and verify everything before it ships.
